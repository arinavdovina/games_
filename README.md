# Игровая мастерская — конструктор промптов

Готовый статический сайт для GitHub Pages. Выбирайте язык, уровень CEFR, возраст, свою лексику и грамматику, одну из 11 механик, встроенные или собственные иллюстрации для каждого игрового элемента.

## Как опубликовать

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория: index.html должен лежать в корне, рядом с app.js, core.js, style.css, папками art и vendor. Сам ZIP загружать вместо файлов не нужно.
3. Откройте Settings → Pages. Выберите Deploy from a branch, ветку main и папку / (root), затем Save.
4. После публикации откройте адрес, показанный GitHub Pages.

Не нужны npm, сборка, ключи API или сервер. Все пути относительные. Иллюстрации разбиты на небольшие файлы, чтобы их можно было загрузить через веб-интерфейс GitHub. Загружайте также все вложенные папки.

## Как пользоваться

1. Укажите язык, уровень и учебный материал. Кнопка «Заполнить пример» заменяет учебные поля демонстрационными данными.
2. Выберите механику. Для переливашек добавьте минимум две категории. Для бинго предусмотрено 9 клеток, для захвата территории — 8 заданий.
3. Оставьте картинки или загрузите свои PNG, JPG, WebP, GIF, автономные SVG (до 8 МБ каждый). Замены хранятся отдельно для каждой механики. Кнопка «Вернуть исходную» отменяет замену.
4. Нажмите «Собрать промпт». Можно скопировать текст, скачать TXT или ZIP с промптом, спецификацией и выбранными картинками.
5. Отправьте промпт и картинки ИИ, который умеет создавать HTML-файлы. Если сервис не читает ZIP, распакуйте его и приложите файлы отдельно.

**Этот сайт создаёт промпт и комплект материалов, а не генерирует саму игру.** Полученную от ИИ игру необходимо проверить перед использованием.

## Сохранение работы

Текстовые настройки сохраняются в localStorage браузера. Собственные картинки остаются в памяти до закрытия/обновления страницы: используйте «Сохранить проект», чтобы скачать JSON с настройками и загруженными файлами. Кнопка «Открыть проект» восстанавливает их. Встроенные картинки повторно в проект не включаются.

Файлы никуда не отправляются. Нет аналитики, внешних шрифтов, CDN или сетевых запросов к сервисам генерации. Копирование может потребовать HTTPS; если буфер обмена недоступен, выделенный текст можно скопировать вручную.

## Локальный запуск

Откройте index.html в современном браузере. Для наиболее предсказуемой работы браузерных функций используйте локальный HTTP-сервер или GitHub Pages. Иллюстрации оптимизированы в WebP. Для публикации распакуйте архив и загрузите файлы и папки из него, а не сам ZIP.

## Иллюстрации и механики

Фоны и отдельные персонажи сгенерированы ИИ для этого набора. Игровые детали представлены SVG. Пользовательские изображения используйте с необходимыми правами.

Механики — самостоятельные учебные адаптации: «Зума» представляет выбор слова из цепочки, «Переливашки» — классификацию по колбам, «Верёвочки» — продвижение персонажа за ответы. Это не точные копии сторонних игр.

JSZip включён локально, его лицензия находится в vendor/JSZip-LICENSE.md.
